# ImShark 0.9.1

ImShark is a Dear ImGui desktop packet analyzer for capture files and live network traffic.

0.9.1 is the first published 0.9 release: the 0.9.0 tag never produced packages because the Windows test build failed. It contains everything planned for 0.9.0 plus the fixes and interface work below.

## Changes in 0.9.1

- **Refreshed interface:** tuned dark and light themes with one accent color and crisp text on scaled displays; coloring rules stay readable in the dark theme and the selected row stands out in both themes.
- **Welcome screen:** Open / Start live capture, recent files and a drop hint instead of an empty list.
- **Toolbar and status bar:** a toolbar (View > Toolbar) with shortcut tooltips; the status bar shows displayed/total and selected packets.
- **Layout:** a visible, draggable list/details splitter, a hex view sized to its content, and the window size and position remembered between sessions.
- **macOS bundle identifier:** the app and DMG now carry `com.imshark.app` as `CFBundleIdentifier` (it was empty).
- **Windows build:** fixed the MSVC test build failure that stopped 0.9.0 and made text fixtures check out with LF on every platform.
- **Testing and CI:** 43 headless UI interaction tests (menus, context menus, dropped files, exports); CI now runs on every push and pull request, including Windows.

## Changes from 0.9.0

This minor release introduces database session tracking, rich query and row decoding for PostgreSQL and MySQL, and enhanced RPCSEC_GSS handling for ONC RPC / NFS.

- **Database Session Table:** Track connection-level state in `db_session.{h,cpp}` for PostgreSQL and MySQL with strict memory bounds and caps (256 statements, 64 portals, 1024-byte queries, 128 columns).
- **PostgreSQL Extended Query & Values:** Decode Parse, Bind, Describe, Execute, and Close messages; map prepared statements and portals to query text; decode typed parameters and DataRow values (int, float, numeric, date, timestamp, uuid, bytea, JSON); recognise text and binary COPY data (`PGCOPY`).
- **MySQL Result Sets & Prepared Statements:** Track response phases in flight (column definitions, EOF, rows, OK); decode text rows and binary result set rows (null bitmap and column types); resolve `COM_STMT_PREPARE` statement IDs to their queries and decode `COM_STMT_EXECUTE` parameters.
- **RPCSEC_GSS Handling:** Identify RPCSEC_GSS credentials, integrity/privacy wrapped arguments, and context messages for NFS/RPC without treating them as plain arguments; track wrapped status in the RPC session table.
- **New Filter Fields:** Added `pgsql.statement`, `pgsql.value`, `pgsql.count`, `mysql.value`, and `mysql.statement_id`.

## Downloads

| System | Package |
|---|---|
| Linux x86_64 | AppImage, DEB or tar.gz (Ubuntu 24.04 baseline) |
| macOS Apple Silicon | DMG |
| Windows x86_64 | ZIP |

Compare your download's SHA-256 digest with `SHA256SUMS.txt`. Linux and macOS support libpcap live capture with the required device permissions. The Windows package supports offline capture analysis; live capture needs a separate Npcap-enabled build. The macOS application is ad hoc signed, without Developer ID signing or notarization.

All platform Release builds run CTest before packaging. Publication also requires sanitizer/minimal regressions and the Linux Docker test, which opens the sample capture with Mesa software OpenGL and verifies the installed DEB in a clean Ubuntu image. Linux screenshots and logs are available in the associated Actions run.
