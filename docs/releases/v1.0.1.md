# ImShark 1.0.1

ImShark is a Dear ImGui desktop packet analyzer for capture files and live network traffic.

1.0.1 fixes the Windows package, which closed without a window on machines without an OpenGL 3.2 driver, and smaller
problems found while testing it on a clean Windows machine. Nothing covered by [docs/COMPATIBILITY.md](../COMPATIBILITY.md)
changes.

## Changes since 1.0.0

### Windows
- Falls back to Direct3D 11 when OpenGL 3.2 is not available, on the graphics card or in software (WARP), so the window
  also opens in virtual machines and remote desktop sessions. `IMSHARK_RENDERER` (`opengl`, `d3d11`, `software`) selects
  a renderer. If none starts, a message box explains why.
- No console window opens next to the program. In PowerShell, use `imshark.exe --version | Out-Host` to see
  command-line output.
- A window as tall as the screen keeps its title bar on screen after a restart.
- The source can be built with optional Npcap live capture through a UAC-elevated helper
  ([validation](../WINDOWS_CAPTURE_VALIDATION.md)). The published ZIP is still built without it.

### All platforms
- Letters the built-in font lacks, such as the Turkish ğ and ı, come from a system font instead of being shown as `?`.
- The Open dialog lists all capture types by default; `.pcap` files were hidden behind the `.pcapng` filter.
- The Export Packets, Save Stream and TLS key log file dialogs open at a usable size.
- The last option of an IPv6 Hop-by-Hop or Destination Options header is no longer read past the end of the header
  when its declared length is too long (found by fuzzing).

## Known limitations

- The Windows package is unsigned, so SmartScreen and UAC show an unknown publisher. It was tested in an Arm64 virtual
  machine under x64 emulation; a test on x86_64 hardware is still pending.
- The macOS application is ad hoc signed, without Developer ID signing or notarization: on first launch allow it under
  System Settings > Privacy & Security > Open Anyway.
- Regular expressions use PCRE2 syntax; patterns relying on ECMAScript-only behaviour may need adjusting.

## Downloads

| System | Package |
|---|---|
| Linux x86_64 | AppImage, DEB or tar.gz (Ubuntu 24.04 baseline) |
| macOS Apple Silicon | DMG |
| Windows x86_64 | ZIP |

Compare your download's SHA-256 digest with `SHA256SUMS.txt`. Linux and macOS support libpcap live capture with the
required device permissions. The Windows package supports offline capture analysis; live capture needs a separate
Npcap-enabled build. The macOS application is ad hoc signed, without Developer ID signing or notarization.

All platform Release builds run CTest before packaging. Publication also requires sanitizer/minimal regressions and the
Linux Docker test, which opens the sample capture with Mesa software OpenGL and verifies the installed DEB in a clean
Ubuntu image. Linux screenshots and logs are available in the associated Actions run.
