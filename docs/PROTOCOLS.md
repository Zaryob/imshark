# ImShark Supported Protocols & Specification References

This document catalogs the network protocols, encapsulations, and applications dissected by ImShark, along with the reference RFC or specification, the implementation file, and what is and is not decoded. RFC numbers link to the RFC editor; other specifications are named without a link. It is a summary: [SUPPORT_MATRIX.md](SUPPORT_MATRIX.md) lists filter fields and framing, and [KNOWN_ISSUES.md](KNOWN_ISSUES.md) the functional limits per area. Specification versions are given where the dissector targets one; where a row says nothing about a limit, check KNOWN_ISSUES before assuming full coverage.
